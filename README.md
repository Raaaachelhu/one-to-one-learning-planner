# 伴学一对一 · 学科一对一销售工作台

暖象牙白、暖灰褐、陶土橘与橄榄绿的学管模板，融合原“首通学科一对一”内容，适用人群改为前端销售顾问。右上角署名 developer Rachel Hu（Shumin）。

## 直接使用

`dist/index.html` 是完整单文件，无框架、无安装、无构建、无API密钥。可离线双击使用；访问官方来源链接时需要联网。GitHub发布包根目录提供同样的 `index.html` 和兼容旧路径的 `one-to-one-offline.html`。

首页为中央鼠标交互粒子雕塑，所有业务导航固定在左侧，点击进入独立工作页，左上角返回粒子主页。手机通过左上角菜单打开左侧抽屉导航。首通页保留完整录入与分析。

粒子使用本地Canvas：桌面42000粒子、手机14000粒子，持续旋转与形态流动，鼠标或触控引起局部旋涡与回聚；可暂停，尊重系统减少动态设置，离开主页或隐藏页面后停止动画。无需GPU扩展、媒体下载或第三方依赖。

## 前端销售流程

- 电话首通：只录地区、年级、多选学科、各科分数与满分。未知留空，0分独立处理；各科独立校验。
- 多科提纲：口述成绩可视化、分数情境追问、每科最多3个年级知识候选方向、进度核对、话术和记录。
- 学科沟通库：原首通版132条原创知识卡，含原五科40条。可复制，也可添加到相同学段、已选学科的本次首通与家长方案（每科最多3条）。保留原来源定位和抽样范围说明。
- 常见顾虑：价格、考虑、时间、效果、学习意愿与已有课程，按追问、证据和下一步回应。
- 家长方案：此时才填姓名。每周全科总预算15—1200整数分钟，各科正整数合计须一致；生成全科HTML与各科3840px宽PNG长图。
- 销售跟进：主动保存匿名或已署名咨询，记录进度、约定日期、结论与历史。相同首通ID再次保存更新，不重复建档。
- 签约交接：学习材料、目标、购买课程与费用、可上课时间、服务承诺、待核对问题六项。可下载TXT草稿；六项补齐后才允许手动标记完成。
- 保留年级知识、原有学员档案、逐题诊断、试题资料、课表与4K导出。家长方案可主动建立咨询档案后安排时间建议；首通分数标注口述待核对，不自动生成已确认逐题诊断。

改变首通输入、知识选择或家长方案条件后，旧方案失效，必须重新生成。

## 知识范围与使用边界

六个年级、九门核心学科共54个对应关系、182个详细单元。按六三制常用年度进度参考；初一物理、初一初二化学说明通常未独立开课，初三生物地理注明复习衔接，高三全部注明综合复习。小学和其他课程保留跨年级能力框架。

不同教材、新旧教材与学校实际进度可能不同；不声称覆盖所有34地区、所有教材全部章节。原132条沟通卡按学段归类，不能当作具体年级已学证明。页内附课程标准及教材参考链接。

不同考试得分率不用于跨科能力排名；口述总分不拆成知识点失分。候选方向先核对已学范围再观察作答，不承诺固定提分、排名或录取。地区页提供核对框架，不输出未经核验的本地录取率与未来政策结论。当前试卷库为公开精选，保留具体试题与索引资料的状态标记。

## 数据保存

默认会话模式，不自动保存首通草稿及姓名。主动加入跟进后仍为会话记录；“资料与设置”可单独开启销售跟进本机保存并导出JSON备份。学员档案使用原有独立本机保存开关和备份格式。

记录仅在当前网址和浏览器，不跨设备或员工共享，无云端CRM、账号权限或自动联系家长。换设备、网址或浏览器需先导出对应备份。销售备份导入按ID新增，相同ID保留当前记录。发布源码中不含真实客户记录。

## GitHub Pages 更新
